7. Restore demo passwords

If a demo login stops working, reset every @demo.local account back to password:

  1. Open a terminal in backend_staging.
  2. Run php artisan demo:reset-passwords.

To rebuild societies, units, and users from scratch:

  1. Open a terminal in backend_staging.
  2. Run php artisan migrate:fresh --seed.
